# PropDevelopment Architecture Project

This repository contains solutions for the PropDevelopment architecture and
security course project. The tasks use a fictional property development company
to explore data security, application security reviews, partner integrations,
and Kubernetes security controls.

## Project structure

- `Task1/` — data classification, risk assessment, and security mind map.
- `Task2/` — security checklist for business systems.
- `Task3/` — C4 diagrams and requirements for external integrations.
- `Task4/` — Kubernetes RBAC role design and supporting scripts.
- `Task5/` — Kubernetes network policies and traffic isolation.

Each task is maintained in its own directory. See the task-specific files for
the analysis, assumptions, and implementation details.
