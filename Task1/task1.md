# Задание 1. Проверочный лист по безопасности данных

## Результат

Mindmap с категориями данных, рисками, оценками и обоснованиями:
[data-security-mindmap.drawio](./data-security-mindmap.drawio).

Диаграмма подготовлена с использованием ИИ и требует проверки и утверждения
владельцем данных.

## Как создавалась mindmap

1. Из описания компании выписаны основные процессы и данные: продажи и
   бронирование недвижимости, онлайн-сделки, услуги для собственников, ремонты,
   платежи, отчётность и взаимодействие с партнёрами.
2. По C4-модели уточнены системы и хранилища, в которых обрабатываются эти
   сведения: CRM клиентов и собственников, приложения сделок и онлайн-туров,
   сервис ЖКУ, базы данных и DWH/BI.
3. Данные сгруппированы по четырём категориям: публичные, внутренние,
   конфиденциальные и секретные. Категория относится к содержанию и
   предполагаемому режиму доступа к данным, а не только к системе, где они
   хранятся.
4. Для каждого набора данных выбраны относящиеся к нему риски из перечня задания:
   утечка, потеря, искажение, некачественные данные и обесценивание.
5. Риски оценены по возможному влиянию на клиентов, сделки, оказание услуг и
   работу компании. В mindmap для каждого риска приведено краткое объяснение
   оценки.

## Подход к классификации и оценке

Категории в диаграмме являются предлагаемой внутренней классификацией для
PropDevelopment. ISO/IEC 27001 и ISO/IEC 27002 использованы как контекст
управления информационной безопасностью и обращения с информацией; конкретный
набор из четырёх категорий не следует считать предписанной стандартами
таксономией.

Оценка «незначительный — значительный — критический» отражает потенциальное
влияние риска. Вероятность инцидента отдельно не оценивалась: исходное описание
не содержит данных, достаточных для такой оценки.

В mindmap включены данные, относящиеся к описанной текущей архитектуре.
Биометрия и автомобильные номера для планируемых сервисов «Умный дом» не
классифицировались как существующие активы: они относятся к отдельному сценарию
задания 3.
